# Requirements

## Must have

- The product is a website, accessible on a laptop, that is simple to use (a new user needs no specialized training or guidance).
- Exams containing the questions and the students' handwritten answers can be uploaded as PDFs or images.
- The teacher can choose from a predefined set of DELF rubrics, which must include at least the B2 written production grids in both the current format (introduced by France Éducation international in September 2022) and the previous format.
- Once the exams are uploaded and the rubric is specified, the teacher sees a panel with the AI grading result: per-exercise scores, the rubric level chosen for each criterion, and the reasoning behind each choice.
- Proper authentication and accounts allowing multiple teachers.
- Each submission has a "Notes" tab whose contents are saved for future reference.
- Exams can be grouped into "Sessions", each corresponding to a class taking an exam at the same time. Cohort-level analytics on common mistakes are shown for each session.
- Student names and other personally identifiable information (PII) are redacted and never stored on the backend.

## Could have

- Support for custom grading rubrics.
- A separate transcription view for checking and correcting discrepancies between the handwritten text and the transcriber's output.
- Splitting bulk PDFs that contain multiple exams into separate submissions.
- Analytics for an individual student across multiple exams (e.g., common mistakes). The student is identified by an anonymous ID, and their name is stored only in the browser.
- The teacher can create and save their own grading of an exam alongside the AI-generated grading.
